# calendar-bench population: 30 planned calendars

The planned calendars of the whole population of the calendar-bench experiment `healthy_lifestyle_promotion`, generated by [calendar-bench](https://github.com/MaaniBeigy/calendar-bench) (MIT licence) and shared by Maani Beigy (folder `progressive_healthy_lifestyle_promotion`, November 2026). The files are copied unchanged.

| Persona | Persons |
|---|---|
| `diligent_anxious_active` | `_0000` … `_0009` |
| `free_spirited_social_student` | `_0000` … `_0009` |
| `unemployed_family_caregiver` | `_0000` … `_0009` |

Horizon: 8 weeks, Monday 6 July to Sunday 30 August 2026, as in `calendar_bench_configs/experiments/healthy_lifestyle_promotion/environment.yaml`. `ics/diligent_anxious_active_0000.ics` is identical to the calendar used so far (`data/diligent_anxious_active_0000.ics`).

## Contents

| Folder | Files | Format |
|---|---|---|
| `ics/` | `<person_id>.ics` | Planned calendar with the planned events and the `[ctx:...]` context episodes. The input of every version of the simulation |
| `persons/` | `<person_id>.json` | calendar-bench person file: `person_id`, `persona_id`, `person_seed`, `persona` (the **sampled characteristics of this person**: Big Five, age, gender, occupation, weekly workouts, ...; and the stages), `days` (the events per day) and `contexts` (the context episodes) |
| `persons/` | `<person_id>_timeline.tsv` | The same calendar as one table, one row per event or context episode (`row_type`, `category`, `name`, `date`, `start`, `end`, `duration_min`, `is_concurrent`, `is_dividable`, `intensity`, ontology URI, ...) |

## Use

Pass a calendar to any version, from the repository root:

```bash
python v3/src/run_simulation.py calendar_bench_population/ics/free_spirited_social_student_0003.ics
```

Version 1 writes its output next to the `.ics`; those files are ignored by git. Versions 2 and 3 write to `v2/output/` and `v3/output/`. See the [manual](../MANUAL.md), section 15.
